How It Works

ระบบต้นแบบแยกข้อมูลสาธารณะออกจากข้อมูลโรงเรียน และคำนวณด้วยสูตรที่ตรวจสอบได้ ไม่ใช้ข้อความ LLM แทนตัวเลข

1. เก็บข้อมูลครัว

เจ้าหน้าที่กรอกอาหารที่เตรียม อาหารที่ไม่เสิร์ฟ และเศษอาหารบนจานแยกกัน รวมถึงของเหลวอิสระและการปนเปื้อน

2. ท่อทาง AI (แนวคิด)

Camera→ Detection / Classification→ Food Category→ Estimated Quantity→ kg Dataset

ในต้นแบบนี้ปริมาณมาจากผู้ใช้กรอก หรือค่า demo — ติดป้าย Estimated / Measured / User Input ชัดเจน

3. สามเส้นทางตัดสินใจ

Route 1

ลดที่ต้นทาง — อัตราขยะ พยากรณ์ส่วนบริโภค แนะนำปริมาณผลิต (Suggested)

Route 2

ใช้ทางการเกษตร — เคมี C:N ความชื้น และกฎตัดสินใจ (rules only)

Route 3

เป้าหมาย & ปรับสูตร — grid search จริงใน JavaScript

4. ความโปร่งใส

ทุกหน้าคำนวณสำคัญมีปุ่ม “คำนวณอย่างไร?” แสดงอินพุต สูตร และตัวเลขที่แทนค่า — สูตรทั้งหมดอยู่ใน js/formulas.js

ข้อควรจำ: Raw Food Waste ≠ Finished Compost — อย่าแนะนำการใช้กับพืชจากขยะดิบเพียงอย่างเดียว
