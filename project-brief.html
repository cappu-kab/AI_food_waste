Food Waste Lab
ระบบจัดการอาหารเหลือในโรงเรียน

สรุปโปรเจกต์แบบสั้น ๆ สำหรับทำสไลด์ พรีเซนต์ และโปสเตอร์ — ครอบคลุมที่มาของปัญหา วิธีทำงานของระบบ (ไม่รวมการเทรน AI) การแสดงผล และสูตรที่ใช้คำนวณว่าจะเอาอาหารเหลือไปทำอะไรต่อ

โรงเรียน / โรงอาหาร สแกนถาดด้วย AI ลดการเหลือ + ใช้ต่อเป็นปุ๋ย เอกสารอ้างอิงสไลด์
สารบัญ 1. ที่มา / ปัญหา 2. เป้าหมาย 3. วิธีทำงาน 4. การแสดงผล 5. สูตรคำนวณ 6. ข้อจำกัด

1 ที่มา / ปัญหา

ในโรงอาหารโรงเรียน อาหารเหลือเกิดได้ทุกวัน ทั้งจาก ทำเยอะเกินแล้วไม่ได้ตัก และจาก ตักแล้วกินไม่หมด

เสียเงิน

ซื้อวัตถุดิบมาทำแล้วไม่ได้กิน

เสียแรง

คนครัวเตรียมอาหารมาทั้งเช้า

กลายเป็นขยะ

กองรวมกัน เกิดกลิ่น และกินที่ฝังกลบ

ช่องว่างเดิม: โรงเรียนมักไม่รู้แน่ชัดว่าเหลืออะไรบ้าง กี่กิโล และของที่เหลือแล้วควรเอาไปใช้ต่อยังไง — จึงวางแผนมื้อถัดไปหรือทำปุ๋ยได้ยาก

2 เป้าหมายของโปรเจกต์

  • วัดและแยกชนิดอาหารเหลือ จากถาดอาหารกลางวัน
  • ลดการเหลือตั้งแต่ต้น โดยแนะนำว่าควรทำอาหารชนิดไหนน้อยลงเท่าไร
  • ใช้ของที่เหลือแล้วให้เกิดประโยชน์ โดยดูคุณสมบัติกองหมัก แล้วปรับส่วนผสมให้เข้าเป้า
  • ทำให้เข้าใจง่าย — หน้าสาธารณะสำหรับศึกษาแนวทาง / หลังเข้าสู่ระบบสำหรับใช้จริงในโรงเรียน

3 วิธีทำงานของระบบ ไม่รวมวิธีเทรน AI

ภาพรวมทั้งระบบ

ถ่ายรูปถาด→ AI แยกชนิดอาหาร→ รวมกับน้ำหนักที่ชั่งจริง→ บันทึกครัว / รายงาน→ แนะนำลดการทำ + ใช้ต่อ

3.1 สแกนถาดอาหาร (มีโมเดลพร้อมใช้)

  • ถ่ายถาดจากด้านบน ให้เห็นขอบถาดทั้งใบ
  • ระบบแยกได้ 5 ชนิด: ข้าว · ผัก · เนื้อ · เมนูผสม · น้ำ/น้ำแกง
  • ใช้ขอบถาดเป็นไม้บรรทัดแปลงพิกเซล → ตารางเซนติเมตร
  • กรอกน้ำหนักขยะรวมที่ชั่งจริง (กก.) แล้วระบบแบ่งเป็นรายชนิดตามสัดส่วนพื้นที่ × ความหนาแน่นโดยประมาณ
หมายเหตุสำหรับพรีเซนต์: เอกสารนี้ไม่ลงรายละเอียดการเทรนโมเดล ใช้โมเดลที่เทรนเสร็จแล้ว (`models/best.pt`) เพื่อสาธิตการใช้งานจริง

3.2 บันทึกข้อมูลครัว

  • กรอกจำนวนผู้กิน, อาหารที่ทำ, ที่ไม่ได้เสิร์ฟ, ที่เหลือบนถาด
  • แยกน้ำซุป และของแปลกปลอม (เช่น พลาสติก) ออกจากอาหารเหลือแข็ง

3.3 สามเส้นทางตัดสินใจ (หลังได้ตัวเลขแล้ว)

เส้นทาง 1 — ลดตั้งแต่ต้น

ดูว่าเหลืออะไรบ่อย แล้วแนะนำว่ามื้อถัดไปควรลดชนิดไหนกี่กิโล

เส้นทาง 2 — ดูของที่มีอยู่

ชื้นเท่าไร ค่าธาตุ (C:N) เท่าไร เหมาะหมักไหม หรือต้องคัดแยก/แยกน้ำก่อน

เส้นทาง 3 — ตั้งเป้าแล้วปรับ

อยากได้ปุ๋ยแบบไหน → ต้องเติมใบแห้ง/แกลบเท่าไรถึงเข้าเป้า

สำคัญ: การลดการทำอาหารวันถัดไป (เส้นทาง 1) เป็นคนละเรื่องกับ “เอาของที่เหลือแล้วไปใช้ต่อ” (เส้นทาง 2–3)

4 การแสดงผลบนเว็บ

หน้าสาธารณะ

สำหรับโรงเรียนที่มาศึกษาแนวทาง — หน้าแรกเกริ่นปัญหา, ตัวเลขตัวอย่าง, กราฟ, ศูนย์เรียนรู้, สูตร

หลังเข้าสู่ระบบ

สำหรับใช้จริง — บันทึกครัว, สแกนถาด, วิเคราะห์, รายงานพร้อมคำแนะนำลด/หมัก/ปรับสูตร

สิ่งที่โชว์ในรายงานหลัก

  • ปริมาณอาหารเหลือรวม · เหลือต่อคน · อัตราการเหลือ
  • แยกชนิด (ข้าว ผัก ผลไม้ เนื้อ อื่น ๆ)
  • สรุปสั้น ๆ เช่น “ควรลดข้าวประมาณ X กก.”
  • มิเตอร์ความชื้น / C:N และสถานะว่าหมักได้ไหม
  • การ์ด “ตอนนี้ → หลังปรับ” และรายการวัสดุที่ควรเติม

5 สูตรที่ใช้คำนวณทั้งหมด

สูตรด้านล่างเป็นสูตรที่ระบบใช้จริงในโค้ดคำนวณ (ไม่ hardcode ผลลัพธ์ในหน้าเว็บ)

A) สูตรพื้นฐานของมื้ออาหาร

อาหารเหลือแข็งรายชนิด

Wᵢ = Unservedᵢ + PlateWasteᵢ

อินพุต: ที่ไม่ได้เสิร์ฟ + เหลือบนถาด ของชนิด i  |  เอาต์พุต: กก. เหลือของชนิดนั้น

อาหารเหลือรวม / อัตราเหลือ

W = Σ Wᵢ   |   WasteRate = (W / Prepared) × 100

ใช้ทำอะไร: ดูว่ามื้อนี้เหลือกี่กิโล และกี่เปอร์เซ็นต์ของที่ทำ

กินไปแล้ว / กินต่อคน / เหลือต่อคน

Consumed = Prepared − W
Consumption/person = Consumed / Diners
Waste/person = W / Diners

ใช้ทำอะไร: เทียบแต่ละวัน และใช้เป็นฐานพยากรณ์มื้อถัดไป

B) เส้นทาง 1 — ลดการเหลือตั้งแต่ต้น

พยากรณ์การกินต่อคน (Weighted Moving Average)

Forecast = Σ(wₖ × Xₖ) / Σ wₖ

อินพุต: ค่ากินต่อคนย้อนหลัง X และน้ำหนัก w (เช่น 1,2,3,4,5)  |  เอาต์พุต: กก./คน ที่คาด

ปริมาณที่ควรทำ / ลดได้ / ขนาดเสิร์ฟแนะนำ

RecommendedProduction = ExpectedDiners × Forecast × SafetyBuffer
Reduction = CurrentProduction − RecommendedProduction
RecommendedPortion = RecommendedProduction / ExpectedDiners

ใช้ทำอะไร: บอกว่าควรลดข้าว/ผัก/ฯลฯ กี่กิโล ในมื้อถัดไป (ค่าเริ่มต้น SafetyBuffer ≈ 1.08)

% การลดอาหารเหลือ (ติดตามผล)

WasteReduction% = (Baseline − New) / Baseline × 100

ใช้ทำอะไร: เทียบกับช่วงก่อนปรับแผนว่าเหลือน้อยลงไหม

C) เส้นทาง 2 — ดูคุณสมบัติของกองอาหารเหลือ

สัดส่วนรายชนิด

Shareᵢ = (Wᵢ / W) × 100

ส่วนแห้ง / น้ำ / คาร์บอน / ไนโตรเจน

DMᵢ = Wᵢ × (1 − Mᵢ)
Waterᵢ = Wᵢ − DMᵢ
Cᵢ = DMᵢ × CarbonFractionᵢ
Nᵢ = DMᵢ × NitrogenFractionᵢ

M, CarbonFraction, NitrogenFraction มาจากตารางอ้างอิงของแต่ละชนิดอาหาร

C:N และความชื้นรวมของกอง

C:N = ΣC / ΣN
Mmix = Σ(Wᵢ × Mᵢ) / Σ Wᵢ

ใช้ทำอะไร: ดูกองชื้นไหม และอัตราส่วนธาตุเหมาะหมักไหมแบบคร่าว ๆ

กฎตัดสินใจคร่าว ๆ (Decision rules)

  • ของแปลกปลอม / อาหารเหลือแข็ง > 2% → คัดแยกก่อน
  • มีน้ำซุป/น้ำแกง > 0 → แยกน้ำก่อน
  • C:N ไม่อยู่ในช่วง 20–40 หรือ ความชื้นไม่อยู่ในช่วง 45–65% → ปรับส่วนผสมก่อนหมัก
  • ผ่านเงื่อนไข → หมักได้
  • สัดส่วนพืช ≥ 85% → หมายเหตุว่าอาจเหมาะกับปุ๋ยไส้เดือนหลังเตรียมวัตถุดิบ

D) เส้นทาง 3 — ตั้งเป้าแล้วปรับส่วนผสม

เป้าตัวอย่าง: ปุ๋ยหมักแบบมีอากาศ · C:N 25–30 · ความชื้น 50–60%

ธาตุและความชื้นหลังเติมวัสดุเสริม

C_added = X × (1 − M_x) × C_x
N_added = X × (1 − M_x) × N_x
CN_new = (C_food + ΣC_added) / (N_food + ΣN_added)
M_new = (W_food·M_food + Σ(X·M_x)) / (W_food + ΣX)
Cost = Σ(X × Price/kg)

อินพุต: กองอาหารเหลือเดิม + ปริมาณวัสดุเสริม X (เช่น ใบแห้ง, แกลบ, ฟาง)
เอาต์พุต: C:N ใหม่, ความชื้นใหม่, ต้นทุน
ใช้ทำอะไร: หาว่าต้องเติมอะไรกี่กิโลถึงเข้าเป้า (ระบบค้นหลายสูตร แล้วเลือกที่ต้นทุนต่ำ / ใช้น้อย)

E) จากรูปถาด → แบ่งน้ำหนักรายชนิด (หน้าสแกน)

แนวคิดการประมาณ (สรุปสำหรับพรีเซนต์)

  • พื้นที่แต่ละชนิดจากภาพ (ตร.ซม.) โดยเทียบกับเส้นผ่านศูนย์กลางถาด
  • สมมติความสูงกองอาหารคร่าว ๆ แล้วถ่วงด้วยความหนาแน่นรายชนิด
  • นำสัดส่วนที่ได้ไปแบ่งน้ำหนักรวมที่ชั่งจริง → ได้กก. ต่อชนิด

น้ำหนักรวมที่ชั่งจริงเชื่อถือได้สูงสุด ส่วนการแบ่งรายชนิดเป็นค่าประมาณจากภาพ

6 ข้อจำกัดที่ควรพูดตอนพรีเซนต์

  • ตัวเลขจากรูปเป็นค่าประมาณ ไม่แทนการชั่งแยกรายชนิดทุกอย่าง
  • ค่า “เหลือกี่ %” จะแม่นขึ้นเมื่อมีรูปถาดเต็มมาตรฐานเทียบ (calibrate)
  • เคมีปุ๋ยหมักคิดจากตารางอ้างอิงของอาหารเหลือดิบ — ยังไม่ใช่ปุ๋ยหมักสำเร็จ
  • อย่าเอาอาหารเหลือดิบไปใส่ต้นไม้ ต้องหมักจนเสร็จก่อน
  • “หมักเสร็จ / สุก” หมายถึงกองไม่เหม็นอาหาร ไม่ร้อนจัด และคล้ายดินแล้ว

โครงสไลด์แนะนำ (ย่อ)

  1. ปัญหาอาหารเหลือในโรงเรียน
  2. เป้าหมายโปรเจกต์ (วัด · ลด · ใช้ต่อ)
  3. ภาพรวมระบบ (ไม่ลงเทรน AI)
  4. เดโมสแกนถาด + หน้าเว็บ
  5. เส้นทาง 1: ลดการทำมื้อถัดไป
  6. เส้นทาง 2–3: ดูของเหลือ → ตั้งเป้า → ปรับสูตร
  7. สูตรสำคัญ 4–6 สูตร (เลือกโชว์)
  8. ข้อจำกัด + สิ่งที่จะทำต่อ
โปสเตอร์: ใช้บล็อกปัญหา 3 ข้อ + โฟลว์ระบบ 1 แถว + การ์ด 3 เส้นทาง + สูตรเด่น 2–3 สูตร (WasteRate, C:N, RecommendedProduction)
